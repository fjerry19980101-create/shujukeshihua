## 三、未采用的数据源及原因

**阿里天池（tianchi.aliyun.com）**：平台数据集下载接口需登录态，匿名 HTTP 请求被 302 重定向回首页，无法在无人工干预的脚本中取数
（`https://tianchi.aliyun.com/api/dataset/download?dataId=...` → 302 → `/`）。本项目未使用模拟登录或 Cookie 注入等方式绕过，
最终以 BCB 官方开放接口替代，辅助源的目标（为 GMV 提供通胀与汇率口径）同样达成。

## 四、非爬虫声明

本项目**未使用**以下任何手段：
- Scrapy / Selenium / Playwright 等抓取框架
- `requests` / `urllib` + 网页 HTML 解析
- 模拟登录、Cookie 注入、验证码绕过
- 任何形式的接口逆向或限流规避

所有网络请求仅指向：①Kaggle 官方数据集下载端点；②Brazilian Central Bank 公开数据接口；③ECharts 官方 CDN（仅用于一次性下载绘图库，运行期不联网）。

## 五、隐私与伦理

- 数据集中不含姓名、证件号、手机号、邮箱等个人身份信息。
- 客户标识 `customer_id` / `customer_unique_id` 为平台脱敏后的哈希串，本文未做任何再识别尝试。
- 地理信息仅精确到邮编前缀（5 位数字），已由平台做聚合处理。
- 评价文本仅在统计层面使用（评分、是否有评论），未做个体引用。
