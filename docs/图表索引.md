## 复现方式

```bash
# 全部重跑（约 40 秒）
python 代码/run_all_figs.py

# 单张重跑，例如图 5-21
python 代码/fig21_延迟与差评_剂量反应图.py
```

|---|---|
| 画布 | 1088 × 794 px |
